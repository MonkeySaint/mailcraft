# Changelog

What changed in each MailCraft release. Help › What's New shows the newest entries from this file.

## Unreleased

- Proofing: grammar checks for article and verb agreement, punctuation spacing and commonly confused words,
  and writing refinements (passive voice, wordy phrases, clichés, informal words, inclusive language).
- Review › Editor opens the Editor pane with a score and the suggestions by group; Spelling and Grammar
  remembers whether it checks spelling only or grammar too.
- Follow Up › Custom keeps the label, start and due dates and the reminder together, and can flag the
  message for its recipients.
- Properties: encryption and signing, Expires after, categories, contacts, Do not AutoArchive, date pickers,
  Select Names for replies and voting presets.
- Insert › Calendar: any calendar, date-range presets, working hours only, a daily schedule or list layout
  and an attached .ics file.
- The Clipboard pane collects copies from the reading pane and other programs, with an Options menu.
- AutoText starts with your name and initials; F3 in a message inserts the entry you started typing.
- Font Color has High-contrast only; Insert › Symbol has the smiling face; F1 in a message opens Writing
  mail help.
- Compose drawing: shapes, text boxes, WordArt and drawing canvases are floating objects you can move,
  resize and type into, with a Shape Format tab; icons, charts, SmartArt and 3D models are sent as PNG and
  can be edited after insert.
- Compose paragraph tools: Borders and Shading, Find and Replace options (wildcards, special characters,
  Highlight All), Insert Hyperlink to places and bookmarks in the message, Sort Text, nine-level lists,
  Draw Table.
- Tasks: the Tasks ribbon and menus act on flagged messages and contacts in the To-Do List.
- Read windows: Edit Message edits the received message in place; commands act on the window's own
  message.
- Recover Deleted Items keeps permanently deleted items across restarts; the status bar shows the mailbox
  quota; Send/Receive groups with their own schedules.
- Stationery, form-field search conditions and the conversation: search term.
- Mail Merge to form letters, mailing labels and envelopes; Calendar Properties and the contact folder's
  Address Book tab; each main window keeps its own calendar.
- Contacts and tasks sync with CardDAV and CalDAV servers; calendars can be published to a WebDAV
  location; other users' and shared IMAP mailboxes can be opened.
- Compose fonts and proofing: installed fonts are drawn in the editor, print preview and PDF, and the Font
  list shows each font in its own face; Set Proofing Language uses Hunspell dictionaries found on the system.
- Apply Styles pane and Modify Style; Browse for Themes and Save Current Theme read and write Office theme
  files.
- Drawings: select several, Group, Align and Distribute; text wraps around drawings; Edit Points, linked text
  boxes and a Format Shape dialog with fill, line, effects and layout.
- Equations reopen for editing; 3D models are shaded.
- Appointments and meetings: time zones, formatted notes, attachments, Importance and Resources; a new
  meeting is sent from its own window. Account calendars sync with CalDAV; Add Holidays.
- View Settings: group by up to four fields, sort by up to four keys, fonts and grid lines, for every
  module; People card views can be sorted and filtered.
- New Data File can write a standalone data file, optionally protected with a password.
- Quick steps carry message options and can send automatically; context menus have access keys.
- Search: Include Older Results searches mail that is only on the server.
- Translate Message with a translation server you set up yourself (nothing is sent until you do);
  Encoding menu; read windows zoom on their own.

## 0.2.0

- Data files: Remove keeps the data file so File › Open Data File can open it again; Data File Properties.
- Close All Items asks before closing edited appointment, contact and task windows.
- Open in New Window opens a second main window; read windows close or move on when their item is deleted
  or moved.
- Focused Inbox sorts new mail by itself; Ignore and Always Move Conversation also catch later replies.
- Compose: Cut, Copy and Paste on the ribbon use the system clipboard; Format Painter, full Font and
  Paragraph dialogs, More Colors, style sets, building blocks, screenshots, equations, a thesaurus and
  Read Aloud.
- People, Tasks, Notes and Calendar have table views with column sets, sorting, filters, conditional
  formatting and saved views.
- Update Folder and Send/Receive All Folders download internet calendars again; Create New Folder makes
  calendar, contact, task, note and journal folders.
- Help: topics for every module with search, a training tour and What's New.
- AutoArchive, S/MIME signing and encryption, and many more File › Options settings take effect.

## 0.1.1

- First release on GitHub, with packages for Linux, Windows, macOS and FreeBSD and a web build.
- Fixes for the web build, the Flatpak and the desktop entry.

## 0.1.0

- Mail with a ribbon, folder pane, message list and reading pane; IMAP, POP3, SMTP and JMAP accounts.
- Calendar, People, Tasks and Notes modules.
- Rules, Quick Steps, search folders, conversations, saved views and conditional formatting.
- Import and export of EML, MBOX, iCalendar and vCard files; printing to PDF.
- A command line tool and an MCP server that run every command.
